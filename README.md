## ✨ Особенности

- 🔄 **Конвертация форматов** - WebP, JPEG, PNG, AVIF, ICO
- 📦 **Оптимизация размера** - сжатие без потери качества
- 🎯 **Гибкие настройки** - контроль качества от 1 до 100
- ⚡ **Высокая скорость** - быстрая обработка даже больших файлов
- 🎨 **Простой интерфейс** - удобная интеграция с любым фронтендом

## 🚀 Быстрый старт

### Предварительные требования

- Node.js 18 или выше
- Yarn package manager

### Установка и запуск

1. **Клонируйте репозиторий**
   git clone <your-repo-url>
   cd image-optimizer-frontend
2. **Установите зависимости**

   yarn install

3. **Запустите проект**
   yarn start

### API

    Для работы конвертора и оптимизации изображений необходимо запустить бэкенд-сервер!

    Backend репозиторий: https://github.com/tirion789/image-optimizer-backend
